# 📝 DevNotes

Aplicação desenvolvida para criação, organização e gerenciamento de anotações de desenvolvimento.  
O projeto foi criado com foco em praticar manipulação de DOM, armazenamento de dados e construção de interfaces modernas utilizando JavaScript.

---

## 🚀 Objetivo do projeto

O DevNotes foi desenvolvido com o objetivo de:

- Praticar JavaScript na criação de aplicações reais
- Melhorar manipulação de DOM
- Trabalhar com armazenamento de dados
- Desenvolver uma interface moderna e responsiva
- Aprimorar organização de código e lógica de programação

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

---

## ✨ Funcionalidades

- ✅ Criar anotações
- ✅ Editar notas
- ✅ Excluir notas
- ✅ Pesquisar anotações
- ✅ Interface responsiva
- ✅ Salvamento automático no navegador
- ✅ Organização dinâmica das notas

---

## 📂 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/johne-lima/DevNotes.git
```

Entre na pasta do projeto:

```bash
cd DevNotes
```

Depois abra o arquivo `index.html` no navegador.
